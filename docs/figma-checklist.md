## 5. Floating mazhab widget

**Нового файла нет, создаётся в итерации 5.**

Наблюдения из Figma:
- Свёрнутое состояние: chip снизу справа, текст «Мазхаб не выбран» (или название выбранного) + шеврон. Точка-индикатор слева (серая = не выбран, цветная = выбран).
- Развёрнутое состояние: компактная карточка с заголовком «Выберите мазхаб по умолчанию:», 2×2 grid тайлов. Каждый тайл — короткое имя жирным (`Хан`) + полное имя мазхаба снизу (`Абу Ханифа`). Внизу ссылка «О мазхабах» с иконкой `Info` — предположительно открывает popup с описанием.
- Widget не скрывает TOC — placement фиксирован в bottom-right.
- Когда глобальный мазхаб выбран — inline-блоки мнений автоматически переключают активную вкладку на этот мазхаб; пользователь может локально переопределить на параграфе, глобальный state не меняется (подтверждено в плане п.5).

Вытекающие задачи (итерация 5 плана):
1. `MazhabContext` + localStorage persistence (`mktba.mazhab`).
2. `MazhabSelector.tsx` — 2×2 grid с brand-specific цветами для каждой школы.
3. Popup «О мазхабах» с кратким описанием каждой школы (текст MVP: абзац на школу, можно захардкодить в JSON-locale).
4. Интеграция с `ArticlePage.tsx` — pre-select активной вкладки в `VersionedParagraphBlock`.
5. Cookie consent не нужен, если не соберём персональные cookies (localStorage `mktba.mazhab` — preference, не PII).
